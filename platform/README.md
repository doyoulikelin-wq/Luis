# 网页运行平台与 iOS 接口

## 使用网页

在仓库根目录执行 `python3 -m http.server 8774 --bind 127.0.0.1`，然后打开 [角色动作工作台](http://127.0.0.1:8774/platform/web/)。网页使用浏览器原生模块和画布，采用内置参数化三维假人、固定相机。它服务于动作控制与证据采集，也可以在手机浏览器查看；网页桌面结果不能充当 iOS 原生实测。

1. 在「动作设置」中选择挥手，分别切换正常、前臂拉长、前臂脱节和手臂抖动。可开启骨架、暂停并逐帧查看同一动作阶段。
2. 点击「导出骨骼」保存本段动画的模型空间逐帧轨迹。使用 `benchmark/motion.py` 加外部冻结标定测量，记录最差骨段、帧、原值和门槛。导入轨迹可回放，包括直接打开 [点头样例](demo/nod.luis.json)。
3. 在「角色试用」里设置角色名、回应风格和服装色，触发相同场景比较措辞和动作。开启本机记忆后可保存、更正、删除称呼。导出角色包再导入会创建新实例，试问称呼可验证两个实例隔离。网页使用固定台词；没有调用在线语言模型。
4. 浏览器把设置和私人称呼保存在当前浏览器的本机存储。清除浏览器存储将删除这些记录。公开导出的角色包只含模板、名称、风格及配色。只有骨段端点的导入数据用来重现骨架几何，无法还原输入角色的网格、衣物、材质、蒙皮或真实手指。

## 从网页迁移到 iOS

| 边界 | 网页初版 | 后续机构端与 iOS 工作 |
| --- | --- | --- |
| 角色制作与发布 | 选内置母版，编辑名称、配色和人格，导入/导出 v1 小包 | 机构资产库和审核权限 → 后台制作任务 → 发布不可变包。VRM/GLB 等资产应通过格式、许可和运行能力检查。 |
| 运行时 | 选择动作、打断、循环、时间定位、骨架显示，绘制模型空间姿态 | 新建原生播放适配器；候选渲染器先用同一测试包比较。按动作意图、时间和能力协商驱动，保持表情、嘴形和回退规则可测。 |
| 性格与记忆 | 两种固定场景和实例级本机称呼 | 人格卡分版本，接入语音和对话模型；服务端按登录机构、用户和角色实例授权。短期上下文、长期事件、用户纠正与删除独立取证。 |
| 行为证据 | 导出整段规范轨迹；浏览器帧刷新与规范轨迹是两种时钟 | iOS 另采真实呈现帧、动作事件、触控、音频停止、前后台恢复及热降频记录。保留设备/系统版本及测试包哈希。 |
| 验收 | 网页可回放相同轨迹，程序审查骨段并输出定位 | 同一角色、动作和事件序列在网页/iOS 配对运行，复用判据与标注。输入是否一致、差异来自渲染/调度/音频/模型均需能定位。 |

### 现行交换格式

- **角色包** `luis.character.v1`：支持的母版引用、名称、人格枚举和服装色。导入时校验版本、格式及字段。该版本面向内置示范模型。正式的外部模型包应另升版本，声明资产哈希、骨架/表情、动作能力、许可、最低播放器及回退策略。[JSON Schema](contracts/character-package.schema.json)
- **轨迹** `luis.motion-trace.v1`：米制、角色局部空间、采样率、标定静止骨长、骨段父子关系，以及每帧秒时间戳和各段 head/tail。连接检查另需独立端点来源与冻结的连接语义。某些合法骨架通过非零偏移的插槽连接；标定文件需要声明同点、独立插槽或不可观测。同一关节点复制成两份仍只有一个观察。端点只有方向轴，不能恢复绕轴自转。兼容数据用严格递增的时间戳导入；不完整数据可以交给离线评分器列出弃权原因。[导出实现](web/pose.js) · [示例](demo/nod.luis.json)
- **结果** `luis.motion-report.v1`：每项输出 pass/fail/abstain、缺失原因、最差帧和值、限值以及参考/轨迹指纹。外部标定应由机构在实验前冻结并与候选产物分开保管。[动作评测](../benchmark/motion-review.md)

### 待实现的机构边界

机构工作区维护模板、创作者/审核者、授权素材和制作任务。对象存储存原始与生成资产，数据库存不可变版本、审批和工作流配置。发布时原子切换清单；签名、资产哈希与客户端回滚需在生产实现中验收。在线陪伴服务管理用户与实例的私人记忆。审核工作流读取经授权的证据副本，公开角色包不能携带私聊和凭据。要决定是否采用某个生成节点、长记忆服务或原生渲染器，先登记[端到端消融计划](../benchmark/experiments/README.md)，记录被比较的产物及操作成本。
